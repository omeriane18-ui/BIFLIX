# BFLIX (Firebase)
1. ارفع كل الملفات إلى مستودع GitHub ثم فعّل Pages (Settings > Pages > main / root).
2. Firebase > Authentication > Settings > Authorized domains: أضف username.github.io
3. Firebase > Firestore > Rules: الصق محتوى firestore.rules ثم Publish.
4. افتح /admin.html وسجّل الدخول بحسابك.
